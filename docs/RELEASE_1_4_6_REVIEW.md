【事实】本轮完成权限注册闭环、虚拟表格混合分页、列宽持久化、菜单按钮权限自动生成、SvelteKit SSR 预取，并完成独立审查与回归。

## 3. 核心决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 独立 npm 包 | 不做 | SDK 随 Django 静态文件分发，避免额外发布链路 |
| 权限注册源 | 内置目录 + 数据库状态覆盖 | 保证初始化前可用，同时支持后台停用即时生效 |
| 字段权限 | 默认拒绝 | 未配置 allow 白名单的字段不可见 |
| 页面权限 | 未登记默认拒绝 | 新页面必须先注册才能展示 |
| 按钮权限 | 菜单表单穿梭生成 | 与参考项目一致，减少手工维护权限码 |

## 4. 实现记录

### 4.1 权限注册闭环

- `permission_registry.py` 定义页面、按钮与内置权限目录。
- `init_menu` 将页面权限码注册为隐藏菜单节点。
- `has_permission()`、`UserProfile.has_perm()` 拒绝未注册权限。
- `api_permission_by_method()` 不再使用通配回退，HEAD 归一化为 GET。
- ABAC 字段策略默认拒绝；`filter_fields()` 要求显式 allow 且命中。
- `enforcePagePermission()` 对 `/static/` 页面执行路径权限守卫，未登记页面拒绝。
- 角色授权只接受注册、启用、可见且插件未停用的菜单。
- 权限目录按用户裁剪，普通用户无法枚举管理端权限码。

### 4.2 前端能力

- `LayuiUI.virtualTable()` 支持服务端分页混合模式、滚动续载、重试、并发响应丢弃和 HTTP 401 统一处理。
- `tableKey` 开启列宽拖拽与本地持久化；本地值按数字或 `NNNpx` 白名单校验。
- 菜单表单新增按钮权限穿梭框，支持生成、替换和幂等更新。
- SDK 支持 bootstrap 快照、fetch 注入、刷新与失效；SvelteKit 服务端预取助手转发认证头。

## 5. 独立审查修复

| 问题 | 处理 |
|---|---|
| 内置目录绕过数据库状态 | 数据库行存在时以其启用/可见状态为准 |
| 按方法权限通配导致越权 | 改为 view/add/edit/delete 显式映射 |
| 虚拟表首页错页与重试错页 | 增加 loaded、requestId 与 lastFailedRequest |
| 模板结果 XSS | 默认转义，显式 `{__html}` 才输出 HTML |
| Token 切换后旧权限残留 | `configure()/setToken()/invalidate()` 清空快照 |
| SSR 未转发 Bearer | `prefetchServerPermissions()` 转发 Cookie/Authorization/X-Token |
| 按钮生成删除插件节点/清空角色授权 | 排除插件节点，角色改用并集 |
| 角色可授予停用或隐藏菜单 | 增加 `validate_assignable_menus()` |

## 7. 回滚方案

1. 回退本地提交：`git revert <commit>`。
2. 数据库：内置权限注册节点由 `init_menu` 管理，可禁用或删除后重新初始化。
3. 前端缓存：重新部署后刷新静态资源缓存参数。
4. 配置回滚：恢复 `LAYUI_RBAC_ALLOW_UNREGISTERED_PERMISSIONS` 与其他 RBAC 设置。
