## 1. 结论（TL;DR）

【事实】本轮完成 Angular standalone 示例、业务 API 字段白名单、内置按钮权限全量预注册、角色树精确回显、虚拟表格列配置，并按参考项目复刻用户管理列表与浅色壳层。
【判断】权限“先注册后使用”链路进一步闭环，前端表格能力增强，核心业务 API 的字段暴露面收敛。
【本期不做】不发布独立 npm 包；不为全部第三方管理端自动重写字段序列化。
【待确认】是否把更多长尾业务 API 接入 `field_whitelisted()`。
【待确认】是否为权限目录提供独立管理页面。
【待确认】是否把内置权限码改为数据库唯一键。
【待确认】是否把参考式列表工具栏推广到全部管理页面。

## 3. 实现记录

### 3.1 Angular standalone bootstrap

- 新增 `/static/sdk/angular/standalone.ts`。
- 提供 `provideLayuiPermission()`、`layuiPermissionGuard`、`bootstrapLayuiStandalone()`。
- 路由支持 `data.permissions` 显式声明，也支持页面权限映射。
- 加载失败自动重试一次，仍未通过跳转 `/403`。
- 新增核心 SDK `permission-client.d.ts` 类型声明。
- Angular 指令保存并恢复元素原始 `display`，避免覆盖 `flex` 等样式。

### 3.2 业务 API 字段白名单

- 新增 `rbac/serializers.py`。
- `API_FIELD_REGISTRY` 注册 RBAC 用户、日志、配置、角色和 ops 服务器、示例商城分类/商品/订单字段。
- `API_NESTED_FIELD_REGISTRY` 注册用户角色与订单明细等嵌套集合。
- `serialize_instance()`、`serialize_rows()` 支持单行与批量序列化，并批量预载策略。
- `field_whitelisted()` 装饰器自动过滤成功响应。
- 显式传入字段只能收窄内置白名单，不能放大。
- ABAC 字段策略注入当前行上下文，可按行隐藏字段。
- 敏感字段名统一剥离，服务器详情不再返回密码/私钥。
- 已接入角色、用户、操作日志、系统配置、服务器、示例商城分类/商品/订单等核心业务接口。

### 3.3 按钮权限全量预注册

- `init_menu` 调用 `register_page_permissions()`。
- 页面权限写入“权限目录”。
- 全部内置按钮动作码写入“权限目录 / 按钮权限目录”。
- 内置权限码在数据库注册前由目录兜底；注册后由数据库启用/可见状态控制。
- 角色授权仍只接受启用、可见、插件未停用的菜单。

### 3.4 角色授权树精确回显

- `buildPermTreeData()` 保留精确授权 ID。
- 渲染完成后执行 `applyExactTreeChecks()`。
- 先清空级联勾选，再按精确 ID 勾选。
- `syncTreeParentStates()` 自底向上计算父节点全选/半选。
- 保存时收集精确勾选 ID，半选父节点不额外写入。

### 3.5 虚拟表格列配置

- `tableKey` 继续启用列宽持久化。
- 新增列顺序与可见列持久化。
- `columnsConfigurable: true` 显示列配置按钮。
- 配置弹窗支持上移/下移、显示/隐藏列。
- 至少保留一列可见。
- 本地存储值做白名单校验；兼容 1.4.6 的索引列宽格式。
- 无 `field` 的列生成稳定内部键，避免重排后状态错位。
- 模板返回值默认转义，显式 `{__html}` 才输出 HTML。

### 3.6 参考式权限列表交互

结合参考项目的通用列表布局与当前 Layui 组件能力，先落地用户管理：

- 查询区在同一卡片内展示关键词、状态、搜索、新增、批量删除和重置。
- 表格增加左侧勾选列、ID 排序、头像列与固定操作列。
- 状态列改为行内开关，保存失败自动回滚 UI 状态。
- 操作列使用蓝色编辑、橙色重置密码、红色删除等图标按钮。
- 新增 `/admin/api/rbac/users/batch-delete/`，批量删除时跳过当前用户和管理员。
- 浅色壳层采用参考项目的白色顶栏和深色侧栏，当前菜单使用蓝色高亮。

权限目录进一步明确语义：

- 目录节点使用保留 `plugin_key=permission_catalog`。
- 目录是注册状态权威来源；业务生成节点停用后权限立即拒绝。
- 角色授权树默认隐藏“按钮权限目录”，但保留页面权限目录，避免同码节点重复。
- 插件不能注册、启用或卸载 `permission_catalog` 保留键。

## 4. 独立审查与修复

| 级别 | 问题 | 处理 |
|---|---|---|
| 🔴 | 角色树点击使用未定义 `$treeContainer` | 改为 `layero.find('#menuPermTree')` |
| 🔴 | 虚拟表格 `setData()` 竞态后 `loading` 死锁 | `setData()` 重置 `loading` 并递增请求代 |
| 🔴 | ABAC 字段策略缺少行上下文 | 注入 `{resource: row}` |
| 🔴 | 列表双重序列化与字段策略 N+1 | 移除视图内重复序列化；批量预载策略与用户上下文 |
| 🔴 | 标准表格普通列未转义 | `LayuiUI.table()` 默认 `escape: true` |
| 🔴 | 角色更新非事务且可能部分提交 | 创建/更新使用事务并捕获编码唯一冲突 |
| 🟡 | 权限目录与生成器可能产生同码节点 | 目录是注册状态权威来源；角色树隐藏重复目录节点但保留已授权 ID |
| 🟡 | 角色树回显超时静默失败 | 渲染就绪前阻断保存，超时给出错误 |
| 🟡 | 虚拟表格空页可能无限续载 | 空页标记 `exhausted` 并终止续载 |
| 🟡 | 未知资源字段序列化可能放行 | 未注册资源默认拒绝并返回空对象 |
| 🟡 | 用户状态切换读改写竞态 | 后端按目标态加行锁更新；前端防重复并回读 |
| 🟡 | SDK 初始化失败阻断应用 | 初始化失败降级，由路由守卫处理 |
| 🟡 | SDK 配置切换后旧响应可能覆盖 | 权限请求加入代际号 |
| 🟡 | 列宽越界与老格式兼容 | 拖拽限制 60~600px；兼容 `120`/`120px` |
| 🟡 | `escapeHtml()` 不转义引号 | 补充 `"`/`'` 转义并保留 `0/false` |
| 🟡 | 菜单图标存储型 XSS | 列表、编辑预览和实时预览统一转义 |
| 🟡 | 穿梭框清空选择不生效 | 空数组也调用 `replace:true` |
| 🟡 | 生成失败仍提示成功 | 失败阻断成功流程 |
| 🟡 | Angular 加载失败静默 | 服务抛错、指令兜底、守卫重试一次后默认拒绝 |
| 🟡 | 文档未同步 | 更新 SDK、组件、权限与 CHANGELOG |

## 6. 回滚方案

1. 回退本地提交：`git revert <commit>`。
2. 数据库：权限目录节点由 `init_menu` 托管，可按需禁用或删除后重新初始化。
3. 前端缓存：重新部署后刷新静态资源缓存参数。
4. 序列化回滚：移除业务视图上的 `field_whitelisted()` 装饰器即可恢复旧响应字段。
