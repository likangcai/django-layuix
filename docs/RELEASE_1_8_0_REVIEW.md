# 1.8.0 软件生命周期评审报告
作者：影子（Yingzi）　版本：v1.0　日期：2026-11-27

## 1. 结论（TL;DR）
【事实】1.8.0 完成权限体系收口、长表单弹窗治理和多项交互缺陷修复。
【判断】按钮权限从菜单表单迁移到权限目录后，权限定义与授权管理职责更清晰，后续不应再在菜单表单里复制权限码逻辑。
【事实】统一弹窗公共层已提供自动吸底、自适应高度、限高滚动和重新居中，长表单显示不全不再需要逐页补高度。
【建议】下一轮优先处理写接口 CSRF 架构、`bindFormOnce` 实例绑定和角色复制提权面。
【待确认】Session 写接口是否改为强制 Token 认证，需要与前端统一请求封装一起评估。
【待确认】权限目录生成的按钮是否迁移到独立来源标记字段。
【待确认】角色列表与权限目录接口分页是否放入 1.9.0。

## 3. 实现记录

### 3.1 权限体系收口
- 按钮权限从菜单表单穿梭迁移到权限目录页。
- 权限目录支持选择上级菜单与动作创建业务按钮权限，支持删除业务按钮。
- 创建业务按钮时拒绝命中内置权限码，避免内置行与业务行状态权威冲突。
- 角色数据范围选择并入授权弹窗，角色表单不再保留文本型高级面板。
- 角色列表新增行内状态开关、复选框和批量删除。
- 侧栏权限管理分组按参考项目调整为“用户 / 角色 / 菜单 / 部门 / 岗位”。
- 补齐部门、岗位、地区、会员等级页面的 SPA 与服务端路由映射。

### 3.2 长表单弹窗治理
- 菜单表单、角色表单改为自适应高度并受 `80vh` 限制。
- 公共弹窗在限高后按实际高度重新居中。
- 公共弹窗自动识别表单按钮行并统一吸底。
- 修改密码、图标选择、角色权限查看、服务器日志和订单详情弹窗改为自适应高度。
- 长表单内容区使用可见细滚动条，明确提示可继续滚动。

### 3.3 代码审查修复
- `ensureCurrentUser` 增加请求缓存，失败不再写空用户回全局。
- 角色授权弹窗只提交 `menu_ids`、`scope_node`、`scope_depth`，避免覆盖并发修改的基础信息。
- 角色状态切换成功后刷新列表。
- 后端校验 `scope_node` 必须存在且启用。
- 角色批量删除 ID 去重，校验与删除统一到事务。
- 状态接口统一解析 `true/false/1/0/on/off`。
- 角色页、菜单页初始化等待用户信息就绪。

## 4. 风险与修复
| 级别 | 风险 | 处理 |
|---|---|---|
| 🔴 | 长表单固定高度导致按钮不可见 | 公共吸底 + 自适应高度 + 重新居中 |
| 🔴 | 授权弹窗旧快照覆盖并发修改 | 仅提交本次修改字段 |
| 🟡 | 权限码重复导致状态权威不一致 | 创建前校验内置权限码冲突 |
| 🟡 | 角色批量删除校验与删除不一致 | 去重并统一事务 |
| 🟡 | 表单布尔字符串语义反转 | 统一布尔解析 |
| 🟡 | 用户信息并发请求与失败写空 | in-flight 缓存 + 失败不覆盖 |
| 🟡 | Session 写接口 CSRF 面 | 已记录在审查报告，下一轮处理 |
