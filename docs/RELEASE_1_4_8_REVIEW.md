# 1.4.8 软件生命周期评审报告

作者：影子（Yingzi）　版本：v1.0　日期：2026-11-26

## 1. 结论（TL;DR）

【事实】参考项目与当前项目都使用 Layui，但参考项目的弹窗、表单、列表和数据管理更统一，原因是公共层约束更完整，不是 Layui 版本差异。
【判断】当前最需要规避的是“每页各写一套弹窗宽度、内边距、按钮区和数据选项”，应统一到 `LayuiUI.dialog()`、`admin-dialog-form` 和数据字典。
【本期完成】统一弹窗外壳；新增数据字典模型、接口、页面、菜单、权限和内置数据。
【本期不做】不复制参考项目全部业务模块；不引入新的前端框架；不发布独立 npm 包。
【待确认】是否继续集成部门/岗位、地区、会员等级等参考项目数据模块。
【待确认】是否将字典选择器封装为公共表单组件。
【待确认】是否把更多系统配置迁移为“字典 + 配置项”组合模型。

## 2. 参考项目为什么更统一

| 维度 | 参考项目 | 当前项目此前 | 结论 |
|---|---|---|---|
| 弹窗 | `func.js` / `common.js` 统一 `showWin`，固定 `layui-layer-admin` | 各页直接 `LayuiUI.dialog`，宽度、内边距、按钮区各自定义 | 缺少公共壳层 |
| 标题与按钮 | 主题 CSS 统一标题、按钮色、圆角 | 页面级样式覆盖，主按钮落点不一致 | 颜色不是主因，约束才是 |
| 表单 | `model-form` + 公共 label/input/switch/select 组件 | 表单模板分散，padding 与 label 宽度不一致 | 缺少表单规范 |
| 列表 | `toolbar` + 公共 table 封装 + 行操作 widget | 页面自绘查询区、工具栏和操作按钮 | 缺少列表规范 |
| 数据管理 | 字典、配置、部门、岗位、地区等通用模型 | 只有系统配置，缺少共享字典层 | 数据层缺口 |
| 交互 | 编辑/删除/批量操作/状态切换走同一套事件 | 状态开关、弹窗、删除确认分散实现 | 交互入口不统一 |
| 视觉 | 主题 token + 公共组件 | 页面局部 CSS 多，容易互相覆盖 | 页面级复制导致漂移 |

## 3. 根因判断

1. **不是 Layui 落后**：参考项目同样使用 Layui，差异来自公共组件层。
2. **是缺少“弹窗外壳”**：当前弹窗没有统一 skin、标题高度、关闭按钮、按钮区、最大高度和滚动策略。
3. **是缺少“表单规范”**：label 宽度、输入区、必填标识、保存/取消位置各页不同。
4. **是缺少“数据管理层”**：状态、类型、下拉项散落在页面中，无法复用、无法统一授权。
5. **是页面级复制过多**：一旦某个页面调了颜色或间距，其他页面不会跟随，整体自然不统一。

需要主动规避：

- 不再在页面内重复定义 layer 标题、按钮、圆角和阴影。
- 不再为每个页面单独写一套查询栏和操作列样式。
- 不再把状态值硬编码在多个前端页面。
- 不再用“换颜色”代替组件层收敛。

## 4. 本期实现

### 4.1 统一弹窗

- `LayuiUI.dialog()` 默认 `skin: 'layui-layer-admin'`。
- 统一标题栏、关闭按钮、圆角、按钮区背景和主/次按钮。
- `maxHeight` 不再只是传入配置，而是实际设置内容区滚动。
- 删除确认弹窗使用同一皮肤。
- 新增 `.admin-dialog-form` 统一表单内边距、label 宽度和输入区。

### 4.2 数据字典

- 新增 `Dictionary` / `DictionaryItem` 模型与 `0014` 迁移。
- 新增字典 CRUD、字典项 CRUD、启用项读取接口。
- 新增“数据管理 → 字典管理”菜单和 `/static/layui/pages/dict.html`。
- 左侧字典、右侧字典项；支持搜索、分页、状态、默认项、系统内置保护。
- 注册 `dict:view/add/edit/delete` 权限与页面路径。
- `init_menu` 幂等补齐通用状态、用户性别、通知类型三个内置字典。

### 4.3 开发规范

- 新弹窗必须走 `LayuiUI.dialog()`。
- 新表单优先使用 `admin-dialog-form` 与 `standard: true`。
- 新枚举先建数据字典，再写页面。
- 业务页面读取启用项统一走 `/dictionaries/options/<code>/`。

## 6. 回滚方案

1. 回退本地提交。
2. 回退迁移 `0014` 前先备份字典数据；生产环境不建议直接反向迁移。
3. 页面可单独移除“数据管理”菜单，不影响原 RBAC 权限链。
4. 弹窗样式回滚：移除 `LayuiUI.dialog` 默认 skin 与 `admin-dialog-form` 样式即可，不影响业务接口。

## 7. 后续建议

优先顺序：

1. 部门 / 岗位 / 地区等组织数据（高价值，需与数据范围模型打通）。
2. 字典选择器公共组件（前端复用价值高）。
3. 系统配置分组与配置项（与字典模型边界需再确认）。
4. 参考项目式批量操作工具栏（低风险，收益中等）。
