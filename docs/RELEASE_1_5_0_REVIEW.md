## 3. 实现记录

### 3.1 官方省市县数据

- 新增 `django_layuix/rbac/data/china_regions.json`。
- 数据量：3214 条。
- 层级：省级 34、地级 333、县级 2847。
- 来源：民政部国家地名信息库公开接口。
- 台湾、香港、澳门使用标准省级代码归一化。
- `init_menu` 在地区表为空时自动导入种子。

### 3.2 更新脚本

- 新增 `scripts/update_regions_from_mca.py`。
- 支持 dry-run、输出文件、超时、`--apply`。
- 抓取后校验数据量、层级分布和重复编码。
- 数据异常时拒绝覆盖现有种子。
- 新增 `load_regions` 管理命令，支持 `--file`、`--truncate`、`--dry-run`。

### 3.3 用户部门岗位

- `UserProfile` 增加 `department`、`position` 外键。
- 部门或岗位删除时使用 `SET NULL`，不删除用户。
- 用户列表返回部门/岗位 ID 与名称。
- 用户新增/编辑表单增加部门、岗位下拉框。
- 新增 `/admin/api/rbac/users/org-options/`，只返回启用部门与岗位。
- 字段白名单加入用户组织字段。

### 3.4 导入导出

- 新增通用 CSV 导出接口。
- 新增通用 CSV 导入接口，支持 `insert` 与 `upsert`。
- 支持部门、岗位、地区、会员等级。
- 导入自动处理上级编码，支持父记录与子记录在同一文件。
- 单次最多 10000 行、5MB。
- 返回新增、更新、跳过、失败明细。

### 3.5 批量操作

- 新增批量启用/停用接口。
- 新增批量删除接口。
- 部门/地区批量删除会保护仍有未选中下级的节点。
- 单次最多 500 条。
- 四个页面统一增加勾选列和表格工具栏。

## 4. 风险与修复

| 级别 | 风险 | 处理 |
|---|---|---|
| 🔴 | 官方数据不完整时覆盖现有种子 | 校验行数、层级分布、重复编码，不通过则中止 |
| 🔴 | 导入父级缺失导致层级错误 | 第一轮写入记录，第二轮按 parent_code 绑定，并返回错误明细 |
| 🔴 | 批量删除父节点造成误删 | 存在未选中下级时跳过父节点 |
| 🟡 | 用户组织字段影响旧用户接口 | 字段可选、编辑未传时保持原值 |
| 🟡 | 批量状态误操作 | 批量接口要求 edit 权限并返回更新数量 |
| 🟡 | 导入更新越权 | `upsert` 同时要求 add 与 edit 权限 |
