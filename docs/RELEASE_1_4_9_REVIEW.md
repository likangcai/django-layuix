## 3. 实现记录

### 3.1 部门

- 新增 `Department` 模型。
- 支持公司、子公司、部门、小组四种类型。
- 支持上级部门、负责人、电话、邮箱、排序、状态和备注。
- 部门树与表格联动，支持添加下级。
- 更新禁止形成环路；存在下级时禁止删除。

### 3.2 岗位

- 新增 `Position` 模型。
- 支持名称、编码、排序、状态和备注。
- 编码唯一，提供标准列表、搜索、新增、编辑、删除。
- 使用 `position:*` 权限码。

### 3.3 地区

- 新增 `Region` 模型。
- 支持省、市、县区、街道四级结构。
- 支持行政编码、区号、邮编和拼音。
- 地区树与表格联动，支持添加下级。
- 更新禁止形成环路；存在下级时禁止删除。

### 3.4 会员等级

- 新增 `MemberLevel` 模型。
- 支持名称、编码、最低积分、折扣比例、图标、排序、状态和说明。
- 折扣比例限制在 0 到 100。
- 使用 `member_level:*` 权限码。

### 3.5 公共层

- 新增 `data-admin.css`：统一分栏、树、工具栏、表格行操作、表单网格和响应式布局。
- 新增 `data-admin.js`：统一权限判断、树构建、后代节点、状态徽章和删除确认。
- 四个页面共享 `LayuiUI.table()` 与 `LayuiUI.dialog()`。
- 静态文案加入中英文 i18n。
- 四个页面加入前后端页面权限映射。

### 3.6 菜单与权限

- `init_menu` 幂等补齐：
  - 数据管理
  - 字典管理
  - 部门管理
  - 岗位管理
  - 地区管理
  - 会员等级
- 新增权限码：
  - `dept:view/add/edit/delete`
  - `position:view/add/edit/delete`
  - `region:view/add/edit/delete`
  - `member_level:view/add/edit/delete`
- 管理员角色自动获取新菜单。

## 4. 审查与修复

| 级别 | 问题 | 处理 |
|---|---|---|
| 🔴 | 部门/地区可能形成父子环路 | 保存前向上遍历上级链，命中自身则拒绝 |
| 🔴 | 删除父节点造成孤儿数据 | 存在下级时返回 400 |
| 🟡 | 页面重复写布局与行操作 | 抽取 `data-admin.css` 与 `data-admin.js` |
| 🟡 | 新页面可能漏注册权限 | 同步前后端页面映射并加入回归用例 |
| 🟡 | 表格操作列可能被裁切 | 调整列宽并统一行操作容器 |
| 🟡 | 会员折扣可能超出合理范围 | 限制 0 到 100 |
