## 4. 实现记录

### 4.1 核心安全

- `resolve_api_user()`：显式 Token 优先。
- `api_permission_required()`：同步写入 `request.user`。
- `revoke_token()`：验签、绑定用户、旧 Token 指纹落库。
- `token_authenticate()`：移除 POST body Token；SSE 支持 `stream_ticket`。
- `visible_menu_queryset()` / `get_effective_permissions()`：排除停用插件菜单与权限。
- DRF 权限类默认拒绝；Ninja Bearer 使用参数验签。
- AI 配置保存按新增/编辑分别要求 `ai_config:add` / `ai_config:edit`。

### 4.2 前端与参考交互

- 默认浅色主题，样式加载前恢复用户偏好。
- 蓝色渐变顶栏、8px 圆角、消息级别样式、常显标签关闭按钮。
- 角色管理新增“授权”入口：权限树、搜索、全展开/折叠、选中计数、保存按钮防重复。
- HTTP 401 统一清理 Token 并跳转登录。
- 虚拟表格携带 Token，支持字符串模板与错误回调。
- SSE 统一使用 `LayuiUI.realtime` 和短时 ticket。
- SDK 四端补齐 `scopeNodes()` / `abacPolicies()`；空权限码默认拒绝。
