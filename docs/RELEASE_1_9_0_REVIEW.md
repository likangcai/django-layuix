# 1.9.0 软件生命周期评审报告
作者：影子（Yingzi）　版本：v1.0　日期：2026-11-27

## 1. 结论（TL;DR）
【事实】1.9.0 收口写接口 CSRF 面、表单实例绑定、角色复制提权面、权限来源标记与服务端分页。
【判断】写接口强制 Token 是本次唯一破坏性变更，登录/注册已保留公共豁免，前端链路已同步补齐。
【事实】新增 `0021_menu_permission_source` 迁移，内置/业务权限来源不再依赖 `plugin_key` 推断。
【建议】升级后先验证登录、图片上传、数据导入与所有后台写操作均携带 Token。
【待确认】是否后续把 API 中文文案统一用 `gettext_lazy` 包裹，实现真正英文化。
【待确认】是否将 `LAYUIX_REQUIRE_TOKEN_FOR_WRITES=True` 作为长期默认值写入发布模板。
【待确认】是否把分页默认值从 20 调整为 50，需结合真实数据量评估。

## 3. 实现记录

### 3.1 安全加固
- `ApiOriginGuardMiddleware` 增加 `LAYUIX_REQUIRE_TOKEN_FOR_WRITES`，默认开启。
- 后台 API 写请求必须携带 `Authorization: Bearer` 或 `X-Token`；`?token=` 不再作为写请求凭证。
- 登录页直接持久化 `admin_token` 到 `sessionStorage` 与 `localStorage`。
- 图片上传与数据导入补齐 Authorization 头。
- `role_copy` 禁止复制系统角色；非完整权限用户的菜单按可见范围过滤，父角色继承不复制。
- 角色复制增加名称唯一校验、事务与约束异常处理。

### 3.2 交互修复
- 菜单可见开关、菜单类型、配置类型、服务器认证方式改为当前弹窗实例级绑定。
- 角色表单与服务器表单提交改为当前弹窗实例级绑定，避免旧 `layero` 与旧快照。
- 角色列表与权限目录表格改为服务端分页，无 `page` 参数的旧接口响应保持不变。

### 3.3 数据与 i18n
- `Menu.permission_source` 新增内置/业务来源字段，迁移自动回填。
- 权限目录列表、生成、删除统一使用 `permission_source` 判定来源。
- `locale/zh_Hans/LC_MESSAGES/django.po` 补齐后台模板 msgid，`.mo` 同步编译。
- README 与快捷链接文档同时提供 GitHub 与 Gitee 地址。

## 6. 回滚方案
1. 代码回退：`git revert <commit>`。
2. 安全开关回退：设置 `LAYUIX_REQUIRE_TOKEN_FOR_WRITES=False`。
3. 数据回退：撤销 `0021_menu_permission_source` 迁移或忽略该字段。
4. 前端回退：刷新静态缓存参数，恢复实例级绑定前版本。
