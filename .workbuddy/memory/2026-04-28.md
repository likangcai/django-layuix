## iframe 静态页面缓存问题修复（10:40）

### 问题
弹窗仍显示旧版 Layui form 布局（input 框），实际代码已改为自定义 `log-detail-row` 布局。
根本原因：`log.html` 作为 iframe src 被浏览器强缓存，改动不生效。

### 修复
1. `log.html`：加 `<meta http-equiv="Cache-Control" content="no-cache">` 防止自身被缓存
2. `index.html`：iframe src 加 `?_v={% now "YmdHi" %}` 时间戳版本号，每次刷新主页面都加载最新 iframe
3. `admin.css`：移除自定义 `width: 100px` 和 `margin-left: 130px`，还原为只设置 `color`，保持 Layui 官方默认间距

### 经验
- Layui pages/*.html 都是通过 iframe 加载的静态文件，**修改后必须强制破缓存才能生效**
- 弹窗 layer.open type:1 是直接插入 DOM，受父页面 CSS 影响；type:2 是 iframe，独立作用域

### 真正根因
`django_layui/static/layui/css/admin.css` 第 1007 行：
```css
.layui-form-label {
    white-space: nowrap;
    text-overflow: ellipsis;
    overflow: hidden;   ← 这行是错误的，导致 label 文字被截断
}
```
Layui 官方 `.layui-form-label` 默认宽度 80px，但不应加 `overflow:hidden`，是项目自定义 admin.css 加了这条样式导致的。

### 修复
- 移除 `overflow: hidden` / `text-overflow: ellipsis` / `white-space: nowrap`
- 改为 `width: 100px`（适当拓宽），并同步 `.layui-input-block { margin-left: 130px }`
- CSS 静态文件，浏览器强制刷新即可生效，无需重启服务

## 修复角色编辑菜单权限树回显联动 Bug（12:17）

### 问题
新增角色时，菜单权限只勾选了一级菜单下的2项（如"个人中心"+"操作日志"），但编辑该角色时发现同一级菜单下的所有子菜单（包括"系统配置"）都被勾选了。

### 根因
`role.html` 编辑回显使用 `tree.setChecked('menuPermTreeInst', checkedIds)` 设置选中节点。
Layui tree 的 `setChecked` 内部调用 `syncCheckedState`，会触发**父子联动**：
1. 选中子节点 ID=6"个人中心" → 向上冒泡选中父节点 ID=5"系统管理"
2. 选中父节点 ID=5"系统管理" → 向下传播选中其**所有**子节点（包括 ID=8"系统配置"）

数据库保存的 `menu_ids` 是正确的（`[6, 5, 7]`，不含 ID=8），问题仅在前端回显。

### 修复内容（`static/layui/pages/role.html`）
将 `tree.setChecked(checkedIds)` 替换为直接 DOM 操作：
```javascript
// 遍历所有树节点，只勾选 checkedIds 中的 ID
layero.find('.layui-tree-set').each(function() {
    var $set = $(this);
    var nodeId = $set.data('id');
    if (idSet[nodeId]) {
        var $input = $set.children('.layui-tree-entry').find('input[same="layuiTreeCheck"]');
        $input.prop('checked', true);
        // 同步 Layui checkbox 模拟层样式
        $input.next('.layui-form-checkbox').addClass('layui-form-checked');
    }
});
```
- 直接操作 checkbox DOM + Layui 模拟层，不调用 `setChecked` → 不触发 `syncCheckedState` → 无父子联动
- `tree.getChecked()` 仍能正确收集（它通过 `.layui-form-checked` 类查找选中节点）
- 重新打包 `pip install` whl 验证通过

## 修复新增用户保存失败 - API 错误信息未展示（12:23）

### 问题
用户新增用户（username=test）时，请求返回 HTTP 400，前端只显示"网络请求失败"，看不到具体错误。

### 根因
1. 数据库中已存在 `username='test'` 的用户 → 后端 `user_create` 返回 `error_response('用户名已存在', 400)`（HTTP 400 + JSON `{"code":400,"msg":"用户名已存在"}`）
2. jQuery `$.ajax` 对 HTTP 4xx 走 `error` 回调而非 `success`，但 `common.js` 的 `error` 回调没有解析 `xhr.responseText`，直接显示通用"网络请求失败"
3. 导致用户无法看到后端的具体错误消息

### 修复内容（`static/layui/js/common.js`）
`api()` 函数的 `error` 回调改为：
1. 尝试 `JSON.parse(xhr.responseText)` 提取后端的 `msg` 字段
2. 如果解析成功，用 `res.msg` 替代通用错误文案显示 `layer.msg`
3. 同时将解析后的 JSON 传给 `callback`，让调用方也能处理（如前端 `if (res.code !== 200)` 逻辑）
4. 解析失败时 fallback 到通用"网络请求失败"

## 修复 AI 配置列表保存成功后不显示数据（12:38）

### 问题
用户新增 AI 模型配置（智谱 GLM）并保存成功后，列表页面不显示任何数据。curl 测试 `/admin/api/ops/ai/config/list/` 返回数据正常，`ai_config.json` 文件内容也正确。

### 根因
`ai-config.html` 中 Layui table.render 的 `response` 和 `parseData` 配置矛盾：

- `response: { statusCode: 200, ... }` → 告诉 Layui 成功状态码是 `200`
- `parseData` 中 `code: res.code === 200 ? 0 : 1` → 将业务 code 200 转成 Layui 格式的 `0`

Layui table 内部逻辑：`e[r.statusName] != r.statusCode`
- `r.statusName` 默认 `"code"`，`r.statusCode` 被配置为 `200`
- `parseData` 返回 `{ code: 0, ... }`，所以 `0 != 200` 为 `true` → 走错误分支
- 表格显示"请求异常"或无数据

### 修复内容（`static/layui/pages/ai-config.html`）
移除 `response` 中的 `statusCode: 200`，保留 `dataName` 和 `msgName`：
```javascript
// 修复前
response: { statusCode: 200, dataName: 'data', msgName: 'msg' },
// 修复后
response: { dataName: 'data', msgName: 'msg' },
```
Layui 默认 `statusCode` 就是 `0`，与 `parseData` 返回的 `code: 0` 完全匹配。

- `.layui-input-block { margin-left: 140px }` 按最大值对齐
- label 文字大多数 2~4 个中文字（约 56~112px），右边大量空白
- 最长 label"SSH用户名"也只需约 100px

### 修复内容

**1. `admin.css` 全局样式调整**
```css
.layui-form-label {
    width: 100px;         /* 110px → 100px */
    padding: 9px 10px;    /* 9px 15px → 9px 10px，减小左右内边距 */
}
.layui-input-block {
    margin-left: 120px;   /* 140px → 120px（100px + 10px*2） */
}
.layui-form-pane .layui-form-label {
    width: 100px;
    padding: 9px 10px;    /* 同步调整 */
}
```

**2. 页面内联样式同步更新**
- `menu.html`：`.layui-input-block { margin-left: 130px }` → `120px`
- `role.html`：同上
- `ai-config.html`：已经是 `100px` + `120px`，无需修改
- `profile.html`、`log.html`、`user.html`：搜索栏 label 80px，不受影响
